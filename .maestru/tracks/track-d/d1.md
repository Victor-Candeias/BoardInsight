# D1: Dashboard geral (KPIs, distribuições, filtros, aviso de dados desatualizados)

## Implementação

- Backend: `services/periods.py` (períodos/intervalos em hora local), `services/dashboard.py` e `GET /api/v1/boards/{id}/dashboard` (filtros de cartões + `from`/`to`/`granularity`, `stale`, `dataAsOf`).
- KPIs: total, backlog, a fazer, em curso, ativos, concluídos, bloqueados, em atraso, prazo ≤ 7 dias, sem responsável, criados/concluídos no período.
- Frontend: página **Dashboard** (rota `/`, substitui a página inicial) com KPIs ligados à lista de cartões filtrada, aviso de dados desatualizados, controlo de período, gráficos Recharts (`src/charts/`) com tabela acessível equivalente.
- Testes: `tests/test_dashboard.py`, `DashboardPage.test.tsx`. Fixture `synced` movida para `conftest.py`; `testTimeout` do vitest aumentado para 20 s (máquina lenta).
