# D8: Página Horas: relatório de tempo registado por período e utilizador

## Objetivo

Página **Horas** (`/hours`) com o relatório do tempo registado (logged time do Businessmap) num período, para um
utilizador ou para todos. Spec: `d8-spec`.

## Decisões (confirmadas pelo utilizador em 23-10-2026)

- A API key lê o tempo registado de todos os utilizadores.
- O período filtra pela **data do trabalho** (`date` da entrada), não pela data em que foi registado (`logged_at`).
- Subtarefas: opção na página para **incluir ou excluir** (incluídas por omissão).
- Fuso Europe/Lisbon; horas apresentadas em **HH:mm** (ex.: `152:30`).
- Novo pacote de instalação (versão 0.3.0).

## Critérios de aceitação

- [x] O sync recolhe `GET /loggedTime` (com subtarefas) para a collection `logged_times`, só com entradas do board, e
      reconcilia alterações/remoções numa janela recente (`LOGGED_TIME_SYNC_DAYS`); uma falha nesta recolha não falha
      o sync (fica um aviso).
- [x] `GET /api/v1/boards/{id}/hours?from&to&granularity&userId&includeSubtasks` devolve totais, série por período,
      totais por utilizador e a lista de registos.
- [x] Página Horas com período, seletor de utilizador (Todos ou um), opção de subtarefas, KPIs, gráfico, tabela por
      utilizador e tabela de registos em HH:mm; exportação PDF.
- [x] Testes do backend e do frontend passam.
- [x] Pacote `BoardInsight-Setup-0.3.0.exe` gerado.

## Implementação

- Backend: `services/logged_times.py` (recolha, reconciliação e relatório), `iter_logged_times` no cliente, `BmLoggedTime`,
  integração em `services/sync.py` (stats `loggedTimeEntries`/`loggedTimeRemoved`/`loggedTimePages`; `loggedTimeSyncedAt`/`loggedTimeError`
  no board), índices de `logged_times` e `LOGGED_TIME_SYNC_DAYS` (35). Endpoint `GET /boards/{id}/hours` em `api/v1/delivery.py`.
- Frontend: `pages/HoursPage.tsx`, `charts/HoursChart.tsx`, `api/hours.ts`, `formatHours` (HH:mm), prop `display` no `KpiCard`,
  item **Horas** no grupo Equipa.
- Testes: `backend/tests/test_hours.py` e `frontend/src/pages/HoursPage.test.tsx`.
- Versão 0.3.0; pacote `dist/windows/BoardInsight-Setup-0.3.0.exe`.
- Pendente: confirmar `GET /loggedTime` com uma chamada real (não foi possível ler a API key: o `.env` instalado só é
