# A2: Recolher amostras anonimizadas do Board 96; documentar rate limit e paginação

## Como executar

Requer `BUSINESSMAP_API_KEY` no `.env` (ainda não definida em 21-10-2026).

```bash
cd backend && .venv/bin/python -m app.jobs.capture_samples --board 96 --out samples
```

Grava amostras anonimizadas em `backend/samples/` (ignorado pelo Git; rever antes de copiar para
`tests/fixtures/businessmap/`) e um `report_96.json` com: limites reais (`/apiLimits`), quota restante,
paginação, erros de validação dos DTOs (C2) e as chaves reais de `transitions`, `block_times` e
`lead_time_per_column`. Atualizar `businessmap-api-validation` com o resultado.
