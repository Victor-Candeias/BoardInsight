# C6: API e página Cartões (filtros, paginação, detalhe)

## Implementação

- `services/card_query.py`: `CardFilters` + `build_query` (filtros partilhados com dashboards/exportações), `sort_spec` (lista de campos permitidos), `CardEnricher` (nomes de coluna/lane/workflow/tipo/responsável, flags `overdue`/`dueSoon`/`missing`).
- Datas de filtro são dias locais (Europe/Lisbon) convertidos para limites UTC; prazo próximo = 7 dias; cartões com `missingSince` ficam ocultos salvo `includeMissing=true`.
- API: `GET /boards/{id}/cards` (filtros: q, state, status, columnId, laneId, ownerUserId, unassigned, typeId, priority, blocked, overdue, dueSoon, createdFrom/To, endedFrom/To; `sort`, `page`, `pageSize` ≤ 200), `GET /boards/{id}/cards/filter-options`, `GET /boards/{id}/cards/{cardId}` (transições com nomes + `card_events`).
- UI: página **Cartões** (TanStack Table com ordenação/paginação no servidor, filtros no URL) e detalhe do cartão (percurso no board, bloqueio, link para o Businessmap).
- A exportação dos resultados filtrados é feita em F1.
