# C4: Timer systemd de sync (30 min), worker de jobs (MongoDB) e botão de refresh na UI

## Implementação

- Fila `jobs` (`repositories/jobs.py`) com deduplicação de jobs ativos por tipo+payload; `fail_stale` para jobs órfãos.
- Worker `python -m app.jobs.worker [--once]` (SIGTERM limpo) e handlers em `app/jobs/handlers.py`.
- Timer: `python -m app.jobs.sync [--board ID]` — sync de todos os boards ativos + retenção (`services/retention.py`: `raw` > 30 dias, exportações expiradas).
- API: `POST /api/v1/boards/{id}/sync`, `GET /api/v1/boards/{id}/sync-status`, `GET /api/v1/jobs/{id}`; formato de erro uniforme (`api/errors.py`).
- Unidades systemd: `deploy/systemd/businessmap-sync.{service,timer}`, `businessmap-worker.service` (instalação em G1).
- UI: `SyncButton` no cabeçalho (board ativo via `useActiveBoard`/localStorage), com hora da última sync em pt-PT e aviso de dados desatualizados.
