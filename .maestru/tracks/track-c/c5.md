# C5: API e página Boards (trocar board ativo, test-connection, mapeamento de colunas só leitura)

## Implementação

- API (`app/api/v1/boards.py`): `GET /boards?search=`, `POST /boards` (valida no Businessmap, guarda metadados/estrutura e enfileira a 1.ª sync), `GET/PATCH/DELETE /boards/{id}` (PATCH: `enabled`; DELETE remove também cartões, eventos, snapshots, sync_runs e cache de utilizadores), `POST /boards/{id}/test-connection` (verifica metadados, estrutura, cartões ativos — obrigatórios — e arquivados, cycle time, utilizadores e tipos — opcionais; funciona antes de adicionar), `GET /boards/{id}/sync-runs`.
- Mapeamento de colunas só leitura (`services/boards.column_mapping`): coluna → secção → estado normalizado + flag de cycle time.
- UI: página **Boards** (adicionar/testar, pesquisa, ativar/pausar sync automática, selecionar), página de detalhe (mapeamento, lanes/tipos, histórico de syncs, remover) e seletor do board ativo no cabeçalho (localStorage).
- A configuração de sprints por board fica para E5.
