# G8: App desktop WPF (WebView2) a envolver a SPA no instalador Windows

## Objetivo

Dar ao instalador Windows (G7) uma aplicação desktop: uma janela WPF que mostra a SPA atual dentro de um controlo
WebView2. O backend, o MongoDB e os serviços WinSW não mudam. A SPA continua acessível pelo browser e a partir da LAN.

## Âmbito

- Projeto `desktop/BoardInsight.Desktop` (WPF, .NET Framework 4.7.2, x64) e testes `desktop/BoardInsight.Desktop.Tests`.
- Ecrã de espera enquanto a API arranca (`/health`), com "Tentar novamente" e "Abrir no browser".
- Links externos e novas janelas abrem no browser predefinido.
- Compilado em Linux pelo `build-installer.sh` (`dotnet publish`) e instalado em `C:\Program Files\BoardInsight\desktop`.
- O instalador escreve o URL em `HKLM\SOFTWARE\BoardInsight` (`Url`), cria atalhos no menu Iniciar e no ambiente
  de trabalho, instala o WebView2 Runtime se faltar e abre a app no fim.

Fora do âmbito: UI nativa em WPF, notificações, arranque automático com o Windows.

Ver `g8-spec` e `deployment-windows`.
